Flight log

Where it stands

Latest checkpoint on the four frozen evaluation suites (600 fixed tasks each, greedy policy), against the scripted pilot flying the same tasks. Win = the agent arrives where the pilot fails, or both arrive and the agent's weighted cost is lower. Cost is the task's weighted mix of time, path, fuel and exposure, each divided by a straight-line reference, so lower is better and about 1 means "as costly as the naive estimate".

Learning curves

Each point is a checkpoint scored on the frozen suites. Dashed lines are the scripted pilot on the same tasks. Hover for values.

Success rate

Win rate against the pilot

Training rollouts

Cost against the best known flight

median agent cost ÷ best flight found by the planner or the pilot, on the reference subset (1.0 = as good)
